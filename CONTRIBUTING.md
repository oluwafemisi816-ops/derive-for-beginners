# Contributing

Thank you for helping improve this beginner guide.

## How to suggest a change

1. Fork the repository.
2. Create a branch for your change.
3. Edit the relevant Markdown file.
4. Open a pull request with a clear description of what you changed and why.

## What we look for

- Clearer explanations for beginners.
- Corrections when something no longer matches official Derive documentation.
- Better examples that stay technically accurate.
- Fixes for broken links or outdated parameter values.

## What to avoid

- Financial advice or trading recommendations.
- Claims that are not supported by official sources.
- Copying large sections of official documentation without rewriting them in original language.
