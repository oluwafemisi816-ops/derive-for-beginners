# Derive for Beginners

A clear, beginner-friendly learning guide to the Derive ecosystem.

Derive is a decentralized options and perpetuals protocol that settles on Ethereum. It uses zero-knowledge proofs so trades can match quickly off-chain while risk management and settlement still follow rules verified on Ethereum.

This guide explains the core ideas in plain language first, then adds the technical details. It is written for people who are new to derivatives, options, or on-chain trading protocols.

**This is an educational guide only.** It does not provide financial advice, trading recommendations, or instructions for depositing real money. Always do your own research and only use official Derive resources when interacting with the protocol.
